## Requirements

- **macOS** (uses `say` for text-to-speech)
- **pv** — pipe viewer for the slow-typing effect

```bash
brew install pv
```

## Usage

```bash
git clone https://github.com/joeheyming/still_alive.git
cd still_alive
./still_alive.sh
```

Press `Ctrl+C` to exit (and silence GLaDOS).
